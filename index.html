盛裝 Dress Code

著裝建議・三月早春日系柔和色

三月高雄已帶春意，傍晚仍可能微涼。建議以低飽和、柔霧感的日系色調為主，例如生成米白、春櫻霧粉、若葉灰綠、藤霧淡紫與春空灰藍；可搭配薄西裝、針織罩衫或輕質外套，在舒適之餘也與早春宴會氛圍自然相融。

女賓可選雪紡、緞面或柔軟針織；男賓可選米灰、霧藍、淺卡其西裝或襯衫。建議避免全黑、螢光色與過度高飽和色彩。

各項交通建議 (點擊展開詳細路線)

• 搭乘高雄捷運橘線至 捷運鹽埕埔站，由 2 號出口 出站。

• 出站後沿大仁路直行步行約 3 分鐘（約 250 公尺），即可抵達 高雄翰品酒店正門。

• 高鐵左營站：抵達後轉乘高雄捷運紅線至 捷運美麗島站，轉乘橘線往西子灣方向至 捷運鹽埕埔站。

• 計程車乘車：從台鐵高雄車站搭乘計程車約 10-12 分鐘即可抵達；從高鐵左營站車程約 20-25 分鐘。

• 車輛 GPS 導航設定：高雄市鹽埕區大仁路43號。

• 飯店備有專屬地下機械/平面停車場及特約停車位。婚宴賓客可享 免費折抵停車時數，請於離場前向 5 樓福明廳接待處出示停車證明或登記車號。
